# Four services in practice

These are illustrative scenarios, not completed projects, client testimonials, or performance claims. Deliverables remain subject to the agreed scope.

## 01 · See the rooms before the meeting

**Situation:** The designer and maintenance team cannot attend the same facility visit.

**Service:** 360° Site Documentation.

**Handoff and decision:** A dated walkthrough, organized by room and route, gives everyone the same visual reference. They identify visible issues and decide which rooms need a closer visit.

**Scope check:** Agree the areas, viewing format, and access. Use a measurement service if a dimension will govern the design.

## 02 · Give the architect geometry to model

**Situation:** A community center renovation starts with drawings that do not fully reflect the current layout.

**Service:** Mobile Mapping for Revit.

**Handoff and decision:** A registered point cloud of the agreed interior spaces, with reference and coverage notes, supports the architect's existing-condition model and layout review.

**Scope check:** Confirm the import workflow, features, and tolerances. The architect's Revit model is a separate deliverable; identify any connection that needs additional verification.

## 03 · Compare routes across the grounds

**Situation:** The project team is considering several paths between the building, parking, and outdoor activity areas.

**Service:** GNSS & Photogrammetry.

**Handoff and decision:** Georeferenced imagery and scoped, checked surfaces support comparison of visible site conditions and preliminary route alternatives.

**Scope check:** Define the coordinate reference, independent checkpoints, surface meaning, and vegetated gaps. Resolve obscured terrain before relying on a proposed grade or quantity.

## 04 · Check the connection before detailing it

**Situation:** A proposed addition must connect to an existing corridor at specific locations and elevations.

**Service:** Survey-Controlled LiDAR.

**Handoff and decision:** Controlled point clouds, scoped critical features, and independent check results help the designer resolve the connection against the agreed tolerance.

**Scope check:** Name the exact dimensions, tolerance, reviewer, and acceptance method. Resolve exceptions before the data is used for a consequential decision.

## Combine them: a community center renovation

Use the same site to answer four different questions:

| Project need | Service | Recipient and useful next step |
| --- | --- | --- |
| Shared visual context | 360° Site Documentation | Facility team reviews rooms and flags visible concerns |
| Interior geometry | Mobile Mapping for Revit | Architect develops the scoped existing-condition model |
| Grounds and route context | GNSS & Photogrammetry | Site designer compares alternatives and identifies data gaps |
| Critical addition connection | Survey-Controlled LiDAR | Design team reviews checked features against acceptance criteria |

The whole facility can receive visual coverage while only the renovation area needs a point cloud and only the tie-in needs the defined critical checks. Do not expand every service to the full site by default.

**Example brief opening:** “We need to develop a renovation model, compare exterior route alternatives, and resolve the addition's connection to the existing corridor. Confirm the required rooms, site extent, critical features, file handoffs, and acceptance criteria with the receiving designers before capture.”
